# 统一设计语言 · mine-input × 伴生系统

> 来源：用户提供的「伴生系统 / TeBot 即时应用」交互稿（2026-11-04 贴图，3 张，经视觉分析提取）
> 原则：mine-input 是伴生系统生态的成员，**视觉语言与交互稿保持同族**——深色科幻 + 游戏化 HUD。
> 本文件是线框与 UI 的唯一风格源：改风格 → 改这里 → 重跑 `design/generate_svg.py`。

---

## 1. 色彩 Token

### 基底

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#0E2924` | 全局背景（暗墨绿黑，比纯黑柔和） |
| `card` | `#18352F` | 卡片/模块填充（纯色为主） |
| `card-glass` | `#18352F` @ ~80% | 玻璃质感模块（少量，如悬浮面板） |
| `stroke` | `#2B4B44` | 全部描边/分隔线（统一 1px 细描边） |

### 强调色（低饱和高亮）

| Token | 值 | 语义与位置 |
|---|---|---|
| `gold` | `#D4A857` | **主强调**：等级/数值/积分/进度条/主按钮/选中态 |
| `cyan` | `#388A83` | **次强调**：路径/状态/下一步/定位节点/听写中 |
| `purple` | `#5D3D8C` | 分类强调（推演/计算类功能、分类选中） |
| `red` | `#A84B3D` | 危险/重要/重赛/熔断 |
| `green` | `#4CB368` | 成功/完成/接受 |

> 用色纪律：一页最多金 + 青两个强调主导，紫/红/绿只做状态点缀。

### 文字层级

| 层级 | 色 | 字重 | 字号 |
|---|---|---|---|
| 模块标题 | `#E0E6E4` | Bold | 14px |
| 正文/核心 | `#C8D0CC` | Medium | 12px |
| 弱化/辅助 | `#8A9E99` | Regular | 10px |
| 数值强调 | `gold` 或 `#FFFFFF` | Bold | 12–16px，**等宽字体 + 微发光** |

数字与中文正文形成家族差异：**数字一律 mono**（`+60`、`1/3`、`Lv.6→7`）。

## 2. 几何与节奏

| 项 | 值 |
|---|---|
| 网格 | 8px 基准 |
| 模块间距 | 12px |
| 模块内边距 | 16px |
| 小元素间距 | 8px（图标行距 12px） |
| 圆角 | 大卡 8px ／ 图标容器 6px ／ 小按钮·标签 4px |
| 描边 | 一律 1px（chip 可 1–2px） |

---

## 3. 效果规则（克制使用）

- **发光 glow**：仅用于——选中态、进度条填充、地图路径、数值强调、当前定位节点；其余禁用；
- **渐变**：仅局部功能件——进度条（暗金→亮奶油 左→右渐变）、地图路径（青蓝渐变+外发光）；无大面积渐变描边；
- **装饰**：HUD 细网格背景（低对比）、星点光斑（雾区）、轻微噪点 grain（全局 1 层）；
- **图标**：线性图标 + 深色填充 + 亮色描边，统一描边宽度。

## 4. 组件形态

| 组件 | 形态 |
|---|---|
| **Chip/徽章** | 圆角胶囊，深底 + 1–2px 亮色描边 + 同色字，微发光；语义色见 §1（金=主线/等级、红=重要、蓝青=可接/进行、灰=日常/待实现） |
| **主按钮** | 实心暖金/奶油填充 + 微光晕 + 深色字 |
| **次按钮** | 透明/深底 + 细描边 + 浅字，无光晕 |
| **危险按钮** | 暗红填充 + 红描边 + 红微光 |
| **进度条** | 半透明暗轨 + 金渐变填充 + 柔光 |
| **勾选/清单选中** | 深底圆 + 金描边 + 亮金勾 |
| **开关（设置页）** | 金=开、暗灰=关，与系统开关同构形 |
| **连线（流程/地图）** | 点状虚线 2–3px，同色系发光；仅当前路线带三角箭头 |

## 6. 工程约束

1. **平台控件优先**：Android 系统键盘交互习惯不破坏（长按、滑行、候选翻页手势照常）；风格是皮，不是骨；
2. **对比度**：正文 `#C8D0CC` on `#18352F` 已达可读对比；新增组合须复核；
3. **发光不过载**：同屏发光元素 ≤ 3 处；低端 Android 机型可关 glow（设置项「性能模式」）；
4. **字体**：中文 PingFang SC / Noto Sans SC；数字 mono（SF Mono / JetBrains Mono 档）；
5. **图标**：线性单色描边风，不用彩色 emoji 堆叠（PTT 麦克风等系统惯传除外）。
