## 2. 车道规格

### W1 macos-core（关键路径，预算最重）

- **做什么**：librime（BSD-3）macOS arm64 编译（依赖走 brew，读上游 README-mac.md）；Squirrel fork 开发版构建并安装到 `~/Library/Input Methods`（命名带 dev 标识，**不得破坏用户现有输入法**）；`schema/ping_wubi_mixed.schema.yaml`（rime-wubi 86 + pinyin-simp 混合：形码优先、拼音并联前移、拼音反查）+ 用户词典配置；`build/` 可复现脚本。
- **验收**：构建脚本重跑成功；`rime_deployer`/console 级验证 schema 加载与候选产出；报告给出手工测试步骤（TextEdit 打字）。
- **降级验收**：若 Squirrel.app 构建被环境阻塞 >2h，交付 librime 库 + schema 独立验证 + 精确 blocker 报告。

### W2 voice

- **做什么**：sherpa-onnx 装配（brew/预编译包）；取 SenseVoiceSmall(int8) + Silero VAD + 标点模型（HF 直连失败换 hf-mirror.com）；`voice/poc/` 离线 PoC：WAV→分段→转写→标点→热词后处理；用 `say -o` 生成中文样音做基准；测端到端延迟；`hotwords.txt` 格式与效果对比。
- **验收**：样音转写正确率主观可用；延迟数据（分段数/每段耗时/总耗时）写进报告；模型体积与下载源记录在案。

### W3 ai-spi

- **做什么**：`ai/spi/ai_assist.h` 为唯一契约源（`rescore/complete/correct/suggest(流式)/ingest` + `Candidate/AiContext/InteractionEvent`，对齐技术方案 §7/§8）；C++17；Null 后端 + 800ms 超时包装语义 + 审计日志接口桩；单元测试（断言级即可）；cmake 独立构建。
- **验收**：`cmake -B build && cmake --build build && ctest` 全绿；头文件被 W4 以文档方式引用（契约即协议）。

### W4 hub

- **做什么**：Docker compose（FastAPI+SQLite 起步）：`/v1/auth`（token，多用户分区）`/v1/sync/push|pull` `/v1/ingest` `/v1/suggest`（流式桩）；卷布局与加密预留；llama.cpp 模型服务占位（7B Q4 档，T2 已定）；`hub/smoke.sh` 冒烟脚本。
- **验收**：`docker compose up` 后 `smoke.sh` 全绿（注册→push→pull 一致→ingest→suggest 桩返回）；报告含 curl 命令与输出。

### W5 android

- **做什么**：**先核实再选型**：Trime（osfans/trime，GPLv3）可行性——curl 读 raw README/license，确认 librime-android 构建路径；据此二选一：fork Trime 出 debug APK，或自研 Kotlin IMS 骨架（QWERTY + 候选栏 + PTT 大键，视觉 token 对齐 design-language.md）；minSDK 29。
- **验收**：调研结论（选型+理由+许可证）写进报告；`./gradlew assembleDebug` 出 APK（或诚实 blocker：缺哪个 SDK 组件、哪步失败）。

### W6 design

- **做什么**：`generate_svg.py` 色彩/效果 token 全面换成 design-language.md 深色科幻规范（bg `#0E2924`、card `#18352F`、stroke `#2B4B44`、金 `#D4A857`、青 `#388A83`；发光只在选中/进度/数值/当前态；数字 mono）；16 张全部重生成；XML 校验。
- **验收**：16/16 生成 + 校验通过；报告附 token 对照表（design-language 值 → 代码常量）。

## 3. 工作约定（全部车道）

1. **目录所有权**：只写自己车道目录；根 README/docs 有冲突就报告，不硬改别人的文件；
2. **git**：main 分支小步提交，前缀 `W{n}: `；只 `git add` 自己的文件；
3. **报告**：每车道交付 `{dir}/W{n}-REPORT.md`（做了什么 / 怎么验证 / 遗留与 blocker）；
4. **诚实交付**：阻塞就如实报（缺什么、试过什么、需要什么），绝不编造构建/测试结果；
5. **环境纪律**：Python 依赖用 venv；全局安装（brew 等）在报告注明；禁用 computer_use；
6. **文档先行**：动手前读本计划 + 技术方案 v0.4 对应章节 + 需求文档相关 FR/NFR。
