## 1. 产品定位

**一句话**：一套五笔 86 + 拼音混合、按住即说的输入法，跑在你的 Mac 和 Android 上；背后是你自己的 AI——懂你的上下文，像动态提词器一样跟着你的语音走；习惯数据全端同步，隐私不出你自己的地盘。

**目标用户**：
- 主用户：本人——五笔 86 熟手、语音重度、隐私敏感、多设备；
- 次用户：朋友——需知情同意、自助安装、数据互相隔离。

**核心场景**：

| # | 场景 | 验收要点 |
|---|---|---|
| S1 | 日常混合打字 | 五笔/拼音免切换，30 分钟写作不丢字不切模式 |
| S2 | 语音听写 | 按住右⌘说话、松开上屏，离线、≤1.5s |
| S3 | 动态提词 | 写文档/回消息时 ⌥Esc 唤起；语音中建议实时刷新 |
| S4 | 换设备无缝 | 手机上学的词/热词，Mac 上分钟级可用 |
| S5 | 断网降级 | 打字/语音/端侧 AI 不受影响；同步静默排队 |
| S6 | 朋友安装 | 侧载 + 知情同意 + 数据隔离，自助完成 |

## 2. 功能需求

> 优先级：P0 = 发布必需；P1 = 重要增强；P2 = 可延后。

### FR1 混合输入（P0）

- 五笔 86 与拼音同流混输：形码优先、拼音并联兜底、免切换、免模式感知；
- 拼音反查五笔编码（学习辅助）；
- 上屏行为默认值：四码自动上屏=开、空码顶字=关、候选 6–8 可配；
- 用户词典常开（词频学习 + 自动造词）；
- 自定义短语（日期/邮箱/常用句）。

**验收**：S1；打过的词组第二次输入直达；schema 参数全部可热调不重编译。

### FR2 语音输入 PTT（P0）

- 按住右⌘（可配）开始听写，松开上屏，Esc 取消；
- 说话期间候选区实时滚动转写（流式）；
- 离线管线：VAD → SenseVoiceSmall → 标点恢复 → 热词后处理；
- 热词表（`hotwords.txt`）人工可编辑，且与 L3 自动更新联通；
- 音频不落盘（内存环形缓冲，转写完即弃）；
- 失败兜底：超时/低置信 → 提示重说，不瞎猜上屏；
- Android：键盘上 PTT 大键长按说话，其余同构。

**验收**：S2；安静环境日常可用；Android 与 Mac 转写体验同构。

### FR3 自适应学习（P0/P1）

| 层 | 内容 | 优先级 |
|---|---|---|
| L1 | 词频 + 自动造词（随用随学） | P0 |
| L2 | 习惯画像（简拼率/翻页深度/回改率）→ **只建议不自动改** | P1 |
| L3 | 个人语料留存（默认关，显式开启）→ 自动抽高频专名 → 语音热词 | P1 |

- 「学习数据一键重置」随时回到出厂手感；
- 学习成果跨端共享（在手机学的词 Mac 立即可用）。

**验收**：S4；重置功能可回滚一切学习数据。

### FR4 上下文引擎与交互日志（P1）

- 采集分级、逐项开关、默认仅 C0：
  - **C0**（全端）：输入框前后文、当前应用名、最近输入历史；
  - **C1**（Mac）：按下键盘时触发屏幕快照→OCR、系统音频→ASR 转写（防抖 1–2s）；**仅输入时采集，无持续录音**；
- 敏感应用黑名单；密码框/支付场景（Secure Input）**自动暂停、不可关闭**；
- 交互日志：时间索引事件流（本地 SQLite，可查/可导/可清，默认 30 天滚动）；
- 一键熔断：全局停止一切采集，状态条图标常显指示。

**验收**：开启 C1 后按黑名单应用验证不采集；熔断后日志不再新增。

### FR5 动态提词器（P1）

三种唤起，**只建议不上屏、不抢焦点**（Tab/数字键/点按才采纳）：

1. 随打即出：智能候选单独一组，异步补位；
2. ⌥Esc 快捷键：流式建议面板；
3. 语音实时提词：转写每 300–500ms 增量触发建议刷新。

**验收**：S3；AI 挂掉/超时（800ms）不影响打字与上屏。

### FR6 AI 后端（P0 契约 / P1 场景）

- SPI 契约 `rescore / complete / correct / suggest(流式) / ingest`，本地调用与远程协议同一组方法；
- 部署形态：本地 Hub（默认，Mac Docker）/ 远程 Hub / 混合（端侧 ≤2GB GGUF 兜底）；
- 场景落地顺序：语音同音字纠错 → 候选重排 → 续写联想；
- AI 总开关 + 场景独立开关，默认全关（用户开才跑）；调用审计日志（只记字段）。

**验收**：S5；断网时端侧兜底可用；切换后端零代码改动。

### FR7 数据同步（P0）

- 数据面：L1 userdb、L2 计数器、L3 热词/语料、AI 配置与提示词模板、schema 版本；
- 通道：设备 ⇄ Hub 直连（TLS，可选 E2E）；分钟级最终一致；
- 合并：userdb 取新、计数器增量相加；失败静默排队；
- Hub 多用户分区（朋友数据互不可见）。

**验收**：S4；断网一周后重连，数据完整合并。

### FR8 隐私、安全与知情同意（P0）

- 数据只存于「你的设备 + 你的 Hub」，不经过任何第三方云；
- 高敏采集（C1/C2）**逐项显式同意**，无默认全开；随时可撤回；
- 传输 TLS，可选 E2E（Hub 零知识）；静态加密；
- 一键熔断 + 采集状态常显（菜单/状态条变色）；
- 朋友版走同一份同意清单，每用户独立密钥分区。

**验收**：S6；同意清单与实际采集行为逐项对应。

### FR9 设置与可视化（P1）

- 设置分区：通用 / 输入方案 / 自适应学习 / 采集与上下文 / AI 与同步 / 隐私与数据 / 关于；
- 习惯报告（L2 可视化）：调参建议一键应用或忽略；
- 热键录制控件（PTT / 提词器）；Hub 连接状态与测试。

## 3. 非功能需求

| # | 项 | 指标 |
|---|---|---|
| NFR1 | 打字延迟 | 按键→上屏 ≤ 30ms（本地路径，不经 AI） |
| NFR2 | 语音延迟 | 松开→上屏 ≤ 1.5s；听写中滚动 ≤ 500ms 滞后 |
| NFR3 | AI 延迟 | 异步，超时 800ms 弃本轮；永不阻塞输入 |
| NFR4 | 离线 | 打字、语音、端侧 AI 全离线可用 |
| NFR5 | 资源 | ASR 模型懒加载常驻 ~百 MB 级；端侧 LLM ≤2GB；采集防抖不耗电 |
| NFR6 | 兼容性 | macOS 近两版（Apple Silicon + Intel）；Android 10+（minSDK 待机型确认后定） |
| NFR7 | 可维护 | schema/词库/热词/提示词/模型全配置化，热调不重编译 |
| NFR8 | 数据主权 | 一键导出、一键清空、一键学习重置，全功能可用 |

## 4. 约束与假设

1. **GPLv3**：分发二进制须整体开源 → 定稿即建公开仓；私有配置/语料不进仓；
2. **侧载**：Android 上 APK；Mac 需签名/公证（否则朋友机器被 Gatekeeper 拦）；
3. **假设**：Mac 常驻可当 Hub（已实测 128GB 统一内存，7B Q4 无压力）；Android 机型/系统版本待用户补充（暂按 minSDK 29 基线，影响真机测试矩阵）；
4. **属地合规**：录屏/音频仅支持「本人设备、本人数据」，不提供他人监控能力。
