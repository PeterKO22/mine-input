## 1. 产品定义与设计原则

一套五笔 86 + 拼音混合、按住即说的输入法，跑在 Mac 和 Android 上；背后是自托管 AI（Hub）——懂上下文、能动态提词；习惯数据跨端同步，隐私不出自家地盘。

六条原则（优先级降序）：

1. **一套习惯，全端一致**（词频/画像/热词跨端共享，分钟级一致）
2. **自己的 AI**（Hub 自托管；不出售、不经第三方云）
3. **上下文感知**（采集分级、逐项可控、默认最小）
4. **不阻塞**（按键→上屏永不等待 AI/同步/采集）
5. **隐私默认**（数据只在设备与 Hub；可导可清可熔断）
6. **可分享**（侧载 + 知情同意 + GPLv3 合规）

## 3. 总体架构

```
┌──────────────────────────────────────────────────────────────┐
│             应用层（薄壳，fork 不自研）                          │
│   macOS: Squirrel fork (IMK)      Android: 键盘 App (IMS)     │
│   按键/热键 · 候选框 · 提词面板 · 设置 · 同意流程                 │
└──────────┬───────────────────────────────┬───────────────────┘
           │      共享内核（C++，双端同源）    │
┌──────────▼───────────────┐  ┌────────────▼───────────────────┐
│ 输入引擎 librime          │  │ 语音管线 sherpa-onnx            │
│ ping_wubi_mixed schema   │  │ VAD→SenseVoice→标点→热词        │
│ 用户词典/词频 (L1)        │  │ PTT 状态机（按下→听→松开→上屏）  │
└──────────┬───────────────┘  └────────────┬───────────────────┘
┌──────────▼───────────────────────────────▼───────────────────┐
│        自适应学习 L1-L3  ·  上下文引擎 C0/C1  ·  交互日志        │
└──────────┬───────────────────────────────────────────────────┘
           │  AiAssist SPI（rescore/complete/correct/suggest/ingest）
┌──────────▼───────────────────────────────────────────────────┐
│  端侧兜底：GGUF 小模型（断网可用）                              │
│  AI Hub（Mac Docker 常驻，D8）：模型托管 · 同步中枢 · 交互记忆   │
│  远程 Hub 形态随时可切（同一 SPI 契约 = 远程协议）               │
└──────────┬───────────────────────────────────────────────────┘
           │ TLS（可选 E2E）· 分钟级最终一致
┌──────────▼───────────────────────────────────────────────────┐
│  数据层（全本地/Hub）：userdb · 画像 · 热词 · 语料 · 日志 · 模型  │
│  macOS: ~/Library/Application Support/mine-input              │
│  Android: /data/data/…/files ｜ Hub: Docker volume（加密）     │
└──────────────────────────────────────────────────────────────┘
```

进程模型：输入法主进程内嵌 librime + 语音（模型懒加载）；AI/同步走独立线程池，全异步；Hub 为独立 Docker 容器组。

## 4. 核心输入（FR1）

- **schema `ping_wubi_mixed`**：五笔 86 主 translator + 拼音并联 translator（rime-wubi + pinyin-simp 配方基底）；形码优先、无五笔命中时拼音候选自动前移；保留拼音反查；
- 上屏默认值（D 台账同源）：四码自动上屏=开、空码顶字=关、候选 6–8；
- 自定义短语文件独立维护；
- 全部参数 schema 化热调，不重编译。

## 5. 自适应学习（FR3）

| 层 | 机制 | 同步 |
|---|---|---|
| L1 词频/造词 | librime userdb，上屏即学 | RIME userdb 合并（取新）+ Hub 中转 |
| L2 习惯画像 | 简拼率/翻页深度/回改率/高频词统计 → **建议不自动改** | 增量计数器上行，画像 Hub 合成下行 |
| L3 语料/热词 | 上屏文本留存（默认关）→ 高频专名抽取 → `hotwords.txt` | 热词全端共享；语料加密归集 |

一键学习重置 = L1+L2+L3 全清。学习在哪端发生不重要，成果全端共享。

## 6. 语音输入（FR2）

状态机：`idle →(按下) listening[实时滚动] →(松开) transcribing → 标点+热词 → 上屏`；Esc/左滑取消；低置信提示重说。

- 管线：采集(16k mono) → Silero VAD → SenseVoiceSmall(int8 流式) → CT-Transformer 标点 → 热词后处理；
- **音频不落盘**（内存环形缓冲）；
- 热键：右⌘（D11，可改组合键——个别 app 吞单修饰键时兜底）；Android 为键盘 PTT 大键长按；
- 松开→上屏 ≤1.5s（NFR2）。

## 7. AI Hub 与 SPI（FR6）

- **契约即协议**：`rescore / complete / correct / suggest(流式) / ingest`——端侧后端与 Hub 后端同方法签名，换后端零改动；
- 三形态（D3/D8）：本地 Hub（默认，Mac Docker）/ 远程 Hub / 混合（端侧 ≤2GB GGUF 兜底）；
- 场景顺序：语音同音字纠错 → 候选重排 → 续写联想；
- 工程约束：全异步、超时 800ms 弃本轮、默认全关、审计日志只记字段、上下文最小化（本地后端不受限）。

## 8. 上下文引擎与动态提词器（FR4/FR5）

- 采集分级（D9/D10）：默认 C0；C1 显式开启，**仅输入时触发**（PTT 期间 + 按键触发窗口，防抖 1–2s），无持续环境音；
- 安全输入（密码框/支付）自动暂停不可关；敏感应用黑名单；一键熔断 + 状态常显；
- 交互日志：本地 SQLite，时间索引事件流，默认 30 天滚动，可查可导可清；
- 提词器三唤起：随打异步智能候选 ／ ⌥Esc 流式面板 ／ 语音中随转写（300–500ms 增量）实时刷新；只建议不上屏，Tab/数字/点按才采纳。

## 9. 数据同步（FR7）

- 设备 ⇄ Hub 直连（TLS，可选 E2E）；分钟级最终一致；
- 合并：userdb 取新、计数器增量；失败静默排队；
- Hub 多用户分区（朋友隔离，独立密钥）；
- 同步面：userdb、画像计数、热词、AI 配置/提示词模板、schema 版本。

## 10. 隐私与安全（FR8）

数据只在「设备 + 自有 Hub」；TLS 必开、静态加密、E2E 可选；高敏采集逐项同意（无默认全开）；密码框自动停；一键熔断；朋友版同清单 + 独立分区；仅支持本人设备本人数据。

## 11. 统一设计语言（D13/D14）

> 详见 [../design/design-language.md](../design/design-language.md)（唯一风格源）。摘要：

- **深色科幻 + 游戏化 HUD**，与伴生系统交互稿同族：底 `#0E2924`、卡 `#18352F`、描边 1px `#2B4B44`；
- 强调金 `#D4A857`（数值/进度/主按钮/选中）+ 青 `#388A83`（路径/状态/听写中）；紫/红/绿仅状态点缀；
- 8px 网格、圆角 4/6/8、发光克制（选中/进度/数值/当前态）；数字 mono + 微光；
- 交互设计协作方式（D14）：交互稿以贴图评审，不接入 Figma 自动化；线框由 `design/generate_svg.py` 按 design-language 生成。
